# 🌟 Wellness Dashboard

A comprehensive web-based wellness tracking application that helps users monitor and improve their daily health habits.

![Wellness Dashboard](https://github.com/user-attachments/assets/bf5094b9-a128-4b02-8c79-e9e6bcbb4ef0)

## Features

### 📊 Daily Metrics Tracking
- **Steps Counter**: Track your daily steps with a goal of 10,000 steps
- **Water Intake**: Monitor your hydration with an 8-glass daily goal
- **Sleep Hours**: Log your sleep duration with an 8-hour target
- **Exercise Minutes**: Record your daily exercise with a 30-minute goal
- Real-time progress bars for each metric

### 😊 Mood Tracker
- Track your emotional well-being with 5 mood levels
- Get personalized feedback based on your mood
- View mood history alongside your metrics

### 📈 Weekly Summary
- Average steps, water intake, and sleep over the past 7 days
- Track your wellness streak (consecutive days with logged data)
- Visual statistics to monitor your progress

### 💡 Wellness Tips
- 20+ curated wellness tips covering hydration, exercise, sleep, and mental health
- Random tip generator for daily inspiration

### 🎯 Daily Goals
- Automatic goal checking based on your metrics
- Four main wellness goals to complete each day
- Visual tracking with checkboxes

### 📅 Recent History
- View up to 10 days of your wellness history
- See all metrics and mood in one place
- Track your progress over time

### 💾 Data Persistence
- All data stored locally in your browser (localStorage)
- No account or internet connection required
- Option to clear all data when needed

## Getting Started

### Option 1: Open Directly in Browser
Simply open the `index.html` file in any modern web browser.

### Option 2: Using a Local Server
For the best experience, run a local web server:

```bash
# Using Python 3
python3 -m http.server 8080

# Using Python 2
python -m SimpleHTTPServer 8080

# Using Node.js (npx)
npx serve

# Using PHP
php -S localhost:8080
```

Then navigate to `http://localhost:8080` in your browser.

## Usage

1. **Enter Your Daily Metrics**: Input your steps, water glasses, sleep hours, and exercise minutes
2. **Select Your Mood**: Choose how you're feeling today from the emoji options
3. **Save Your Data**: Click "Save Today's Data" to store your metrics
4. **Check Your Goals**: Mark off goals as you complete them
5. **View Your Progress**: Monitor your weekly averages and history

## Browser Compatibility

This application works on all modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Opera (latest)

## Privacy

All your wellness data is stored locally in your browser using localStorage. No data is sent to any server or third party. Your wellness journey is completely private.

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **Vanilla JavaScript**: No frameworks or dependencies required
- **LocalStorage API**: Client-side data persistence
